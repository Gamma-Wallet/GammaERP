# Document categories

One file per item of the Documents menu. Each lists the category's document types in the base pack, what sits on each side, the kinds of line, the flows and the reversal.

A company can change all of this under System settings › Document types. What a company sees depends on its pack and on the types given to each user. All categories use the same screens: see [the life of a document](../life-cycle.md).

| File | Menu item | Holds |
|------|-----------|-------|
| [sales.md](sales.md) | Documents › Sales | Sales invoices, point-of-sale receipts |
| [purchases.md](purchases.md) | Documents › Purchases | Purchase invoices, customs declarations |
| [transfers.md](transfers.md) | Documents › Goods transfers | Stock moving between places, staff and clients |
| [production.md](production.md) | Documents › Production | Production, unit split |
| [cash-desk.md](cash-desk.md) | Documents › Cash desk | Cash payments and receipts |
| [bank.md](bank.md) | Documents › Bank | Bank payments and receipts |
| [offers.md](offers.md) | Documents › Offers | Sales and purchase offers |
| [orders.md](orders.md) | Documents › Orders | Requests and orders |
| [repairs.md](repairs.md) | Documents › Repairs | Repair intake and offer |
| [contracts.md](contracts.md) | Documents › Contracts | Sales, purchase and point-of-sale contracts |
| [journal.md](journal.md) | Documents › Journal | Journal, depreciation and revaluation sheets |
| [recurring-journal.md](recurring-journal.md) | Documents › Recurring journal | The same sheets, for repeating |
| [reversals.md](reversals.md) | Documents › Reversals | Credit notes and reversal documents |
