# Documents

The Documents menu: every invoice, payment, transfer, offer, order, contract and journal in the ERP. All of them share one list screen and one editor. Their differences are configuration.

**Where:** Documents in the left menu, one item per document category. **Who:** see [life-cycle.md](life-cycle.md#who-may-do-what).
