# Contracts menu

Billing contracts every so many months, and renewing them. A person starts each step: nothing bills or renews by itself. The contracts themselves are documents: see [Contract documents](../documents/categories/contracts.md).

**Where:** Contracts › Invoice run, Contracts › Renewals, and the billing plan on a contract under Documents › Contracts.
